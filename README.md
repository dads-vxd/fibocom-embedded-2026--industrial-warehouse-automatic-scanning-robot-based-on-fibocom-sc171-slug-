## 📖 作品简介

本项目面向工业仓储、物流盘点与物料追踪等应用场景，设计并实现了一套基于广和通 **SC171** 的工业仓储自主扫码机器人系统。系统通过移动机器人平台搭载视觉识别、条码扫描、运动控制、边缘计算与云端管理模块，实现仓库环境中的自主移动、货架识别、条码采集、数据上传与任务管理。

项目以 **SC171** 作为核心智能计算与通信平台，在机器人端完成图像采集、目标识别、扫码结果处理和边缘侧数据分析，并通过网络将仓储信息同步至云端管理平台。下位机控制部分负责电机驱动、传感器采集与机器人运动控制，从而形成“感知—决策—执行—上传—管理”的完整闭环。

该系统可用于仓库盘点、货物追踪、条码信息采集、异常货物识别等场景，能够降低人工盘点成本，提高仓储数据采集效率与自动化水平。

---

## 🧠 核心功能

- **自主移动与运动控制**：通过底盘、电机驱动及传感器完成机器人的前进、后退、转向和定点移动。
- **工业条码自动扫描**：自动识别货架或物料上的一维码/二维码，并提取对应货物信息。
- **视觉识别与边缘计算**：利用 SC171 的计算能力在机器人端完成图像处理、目标检测及识别算法运行。
- **上下位机通信**：SC171 与 STM32 控制器进行数据交互，实现识别结果、控制指令和设备状态的传输。
- **仓储数据管理**：将扫码结果、货物信息、时间记录和设备状态上传至云端平台。
- **Web 可视化管理**：通过网页端查看扫码数据、设备运行状态和仓储任务信息。
- **异常信息记录**：对未识别、重复扫码或异常货物信息进行记录，便于后续人工核查。
- **模块化系统设计**：硬件、固件、边缘算法、云平台和工具程序相互独立，便于维护和扩展。

## 🏗 系统架构

系统整体由硬件执行层、嵌入式控制层、边缘计算层、云端服务层和 Web 管理层组成。

```text
│        数据展示 / 设备状态 / 扫码记录          │
└──────────────────────┬───────────────────────┘
                       │
                       │ 网络通信
                       ▼
┌──────────────────────────────────────────────┐
│                  云端服务平台                 │
│        API 接口 / 数据存储 / 任务管理          │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│             Fibocom SC171 边缘计算层          │
│ 图像采集 / 条码识别 / AI 推理 / 数据处理       │
└──────────────────────┬───────────────────────┘
                       │ 串口 / 通信接口
                       ▼
┌──────────────────────────────────────────────┐
│                  STM32 控制层                 │
│      电机控制 / 传感器采集 / 状态反馈          │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│                 机器人硬件平台                │
│ 电机 / 驱动 / 摄像头 / 扫码模块 / 传感器       │
└──────────────────────────────────────────────┘
```
